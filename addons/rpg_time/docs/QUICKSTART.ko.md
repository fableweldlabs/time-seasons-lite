# Time & Seasons — 빠른 시작

고정된 사계절, 편집 가능한 시간대와 시간 시그널을 제공하는 무료 Godot 시계입니다. 인터페이스, 안내와 선택형 예제는 12개 언어를 지원합니다.

**Addon Only만 다운로드하면 됩니다. 편집 가능한 빛의 계곡 프로젝트와 Windows 데모는 별도의 선택형 다운로드입니다.**

1. Addon Only의 압축을 풀고 `addons/rpg_time`을 프로젝트에 복사하세요.
2. Project > Project Settings > Plugins에서 Time & Seasons를 활성화하세요.
3. 패널의 Language에서 한국어를 선택하세요. 시작일, 시간, 게임 하루의 실제 초를 설정하고 설정 적용을 누르세요.
4. `addons` 밖에 설정을 저장하고 시계를 만든 뒤 시계 씬을 월드 씬으로 끌어다 놓으세요.
5. 하루 구성에서 시간대를 편집하세요. 시계 시험에서는 저장된 파일을 바꾸지 않고 시간을 시험할 수 있습니다. 언어를 바꿔도 직접 저장한 이름은 번역되지 않습니다.

예제 조작: WASD/방향키 이동, E 상호작용, Shift 달리기, 휠 확대/축소, H 사진 모드, Esc 도움말/뒤로. 예제 메뉴에서 언어를 선택하세요. 대화와 간판도 번역되어 있습니다.

검증 대상: Godot 4.7.2, Windows x64. MIT 라이선스 조건에 따라 상업적으로 사용할 수 있습니다. 애드온에는 날씨, 전체 게임 저장, 사용자 지정 달력, 자동 조명이 포함되지 않습니다. 다른 Time & Seasons 에디션을 함께 설치하지 마세요. 업데이트 전에 설정을 백업하세요.
