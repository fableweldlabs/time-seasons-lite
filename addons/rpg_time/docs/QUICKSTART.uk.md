# Time & Seasons — Швидкий початок

Безплатний годинник для Godot із чотирма фіксованими порами року, редагованими періодами доби та сигналами часу. Інтерфейс, інструкції й необов’язковий приклад підтримують 12 мов.

**Достатньо завантажити Addon Only. Редагований проєкт Долина Світла та демо для Windows — окремі необов’язкові завантаження.**

1. Розпакуйте Addon Only та скопіюйте `addons/rpg_time` у проєкт.
2. Увімкніть Time & Seasons у Project > Project Settings > Plugins.
3. На панелі виберіть Українська в полі Language. Укажіть початковий день, час і кількість реальних секунд на ігровий день, а потім натисніть Застосувати налаштування.
4. Збережіть налаштування поза `addons`, створіть годинник і перетягніть його сцену на сцену світу.
5. У розділі Налаштуйте день змініть періоди доби. Випробуйте годинник дає змогу перевіряти час, не змінюючи збережених файлів. Зміна мови не перекладає ваші власні збережені назви.

Керування прикладом: WASD/стрілки — рух, E — взаємодія, Shift — біг, коліщатко — масштаб, H — режим фото, Esc — довідка/повернення. Виберіть мову в меню прикладу. Діалоги та вивіски теж перекладено.

Перевірена платформа: Godot 4.7.2, Windows x64. Комерційне використання дозволено за умовами ліцензії MIT. Додаток не містить погоди, збереження всієї гри, власних календарів чи автоматичного освітлення. Не встановлюйте різні редакції Time & Seasons одночасно; перед оновленням зробіть копію налаштувань.
