# Time & Seasons — 快速入門

免費的 Godot 時鐘，具備固定四季、可編輯時段與時間訊號。介面、說明與選用範例支援 12 種語言。

**只需下載 Addon Only。可編輯的光之谷專案與 Windows 示範是獨立的選用下載。**

1. 解壓縮 Addon Only，將 `addons/rpg_time` 複製到專案。
2. 在 Project > Project Settings > Plugins 啟用 Time & Seasons。
3. 在面板的 Language 選擇繁體中文。設定起始日、時間及遊戲一天的實際秒數，再按套用設定。
4. 將設定儲存在 `addons` 之外，建立時鐘，並將時鐘場景拖入世界場景。
5. 在規劃一天中編輯時段。試用時鐘可讓你測試時間而不變更已儲存的檔案。切換語言不會翻譯你儲存的自訂名稱。

範例操作：WASD／方向鍵移動、E 互動、Shift 跑步、滾輪縮放、H 拍照模式、Esc 說明／返回。在範例選單選擇語言；對話與招牌也已翻譯。

測試環境：Godot 4.7.2、Windows x64。可依 MIT 授權條款用於商業用途。外掛不包含天氣、完整遊戲存檔、自訂日曆或自動照明。請勿同時安裝不同的 Time & Seasons 版本；更新前請備份設定。
