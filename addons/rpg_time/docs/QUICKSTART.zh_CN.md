# Time & Seasons — 快速入门

适用于 Godot 的免费时间插件，提供固定四季、可编辑的日间时段和时间信号，并带有引导式设置及安全预览。界面和快速入门支持简体中文、其他五种语言及英语。

## 简体中文

**使用工具只需下载 Addon Only。Lumen Vale 可编辑示例项目和 Windows 可玩演示均为单独提供的可选下载。**

解压 Addon Only，将 addons/rpg_time 复制到你的项目。在 Project > Project Settings > Plugins 中启用 Time & Seasons。在插件面板的 Language 中选择简体中文。设置起始日期、时间和每个游戏日对应的现实秒数，然后点击应用设置。将设置保存在 addons 之外，再创建时钟。把生成的时钟场景拖入世界场景。

在设置日间时段中调整时段，在预览时钟中推进时间，不会修改已保存的文件。语言设置仅影响插件界面；你保存的自定义名称不会被翻译。

已在 Godot 4.7.2、Windows x64 上验证。采用 MIT 许可证，遵守许可条款即可商用。插件不提供天气、游戏存档、自定义日历或自动光照。可选示例中的相关表现属于独立的示例代码。
