# Time & Seasons — Démarrage rapide

Une horloge gratuite pour Godot avec quatre saisons fixes, des périodes de la journée modifiables et des signaux temporels. Configuration guidée et aperçu sûr inclus. Interface et guide de démarrage en français, cinq autres langues et anglais.

## Français

**Seul le téléchargement Addon Only est nécessaire. Le projet modifiable Lumen Vale et la démo Windows sont des téléchargements séparés et facultatifs.**

Extrayez Addon Only et copiez addons/rpg_time dans votre projet. Activez Time & Seasons dans Project > Project Settings > Plugins. Dans le panneau, choisissez Français sous Language. Réglez le jour, l’heure de départ et les secondes réelles par jour de jeu, puis cliquez sur Appliquer ces réglages. Enregistrez vos réglages hors de addons, créez votre horloge et glissez sa scène dans votre scène de jeu.

Organisez la journée permet de modifier les périodes. Testez votre horloge permet d’avancer le temps sans modifier les fichiers enregistrés. Le choix de langue concerne uniquement l’interface ; vos noms personnalisés ne sont pas traduits.

Vérifié avec Godot 4.7.2 sous Windows x64. Licence MIT, utilisation commerciale autorisée selon ses conditions. L’extension ne fournit ni météo, ni sauvegarde de partie, ni calendrier personnalisé, ni éclairage automatique. Les effets du projet facultatif relèvent de son code d’exemple.
