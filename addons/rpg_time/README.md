# Fableweld Labs - RPG Time & Seasons Free Lite 1.3.3
Enable in Project Settings > Plugins, then use the Time & Seasons dock.
Save profiles and generated clock scenes outside addons. Lite includes the clock, fixed seasons, periods, signals and isolated preview; it does not include a ready-made HUD or lighting rigs.
Do not install Lite and Paid side by side. See package-root README and docs for setup and boundaries.
