# 2.3.0 · Appearance and usability

Clean Light and Dark themes are the primary options. Fableweld and Gold remain optional. Appearance preferences are saved separately from game progress.

Text can be shown at100%,125% or150%. Find action searches visible enabled buttons and moves keyboard focus without executing an action. Scrolling follows keyboard focus. The new controls support all twelve existing languages and refresh when the interface language changes.

Theme resources are lazy and bounded; immutable color palettes are reused. Appearance controllers do not poll the scene every frame.

Preview presentation now skips unchanged requests while retaining simulation ticks and time, play-state, language and authoring invalidation.

The addon is a separate download from the optional example game. Existing authored IDs, game-language settings and save formats are preserved.
