# Time & Seasons Lite 2.2.0

- Five added languages: Polish, Korean, Traditional Chinese, Turkish and Ukrainian. Twelve total.
- Translated interface, quick starts, example dialogue, controls and original signs.
- Cache formatted-message patterns until the language changes, reducing repeat processing.
- No changes to the clock core, public API, profile schema or customer-defined names.
- Translations are AI-assisted, not independently native-speaker certified.
