# Changelog

- New three-step, Lite-only editor workflow with file pickers and optional file details.
- Glossed indigo surfaces, rose actions, clear typography and a live clock dial.
- Original Lumen Vale 3D courtyard: walking, proximity interactions, market hours, resting, seasonal gardens and example lighting driven by the Lite clock.
- Showcase polish: scheduled shopkeeper, animated koi/ripples, cat and bell interactions, wind and chimney smoke, original synthesized sounds with mute, smoother movement/jogging, zoom/photo view, seasonal color transitions, static scenery batching and safe tour cancellation/restart.
- Showcase art rework: articulated original characters, sculpted tabby cat, original koi, branching leafy trees, petal flowers, curved meadow grass, readable typeset signs, timber/plaster detail, rounded cobbles, slate tiles, closer camera and compact controls. Forward+ desktop lighting, seasonal bare trees and roof snow; two original AI-assisted foliage/timber textures.
- Visual depth: surrounding terrain/grove, crafted dormers and facades, garden gate, barrels/produce/carts/ferns, painted face/eye detail, and corrected local slate scaling/color space.
- Smaller illustrated 2D learning example retained separately.
- Install archive restricted to addons/rpg_time, with colocated MIT license, README and docs.
- Stable public display name Time & Seasons; price/license stated separately.
- Core clock API, script UIDs and saved-profile schema unchanged from the public release.
