# Time & Seasons Lite
A free, MIT-licensed world clock for Godot by Fableweld Labs.


This repository contains source, documentation and development checks. Install releases contain only addons/rpg_time, including the license, quick start and docs. The editable example project and playable Windows demo are separate optional downloads. See [the installation guide](addons/rpg_time/README.md).


[Website and download](https://fableweld-labs.itch.io/time-seasons-free-lite) · [Bug reports](https://github.com/fableweldlabs/time-seasons-lite/issues)


## Start with a small working example

[Illustrated clock-signal tutorial and optional 4 KB sample](https://fableweld-labs.itch.io/time-seasons-free-lite/devlog/1725172/tutorial-open-a-shop-with-godot-clock-signals): download Addon Only plus the optional Clock Signal Tutorial from itch.io, copy the addon’s addons folder beside the tutorial project.godot, import in Godot and press F5. The sample shop opens at morning and closes at evening. No large example-game download is needed.

As checked October 26, 2026, itch.io provides Lite 2.1.0; this repository’s addon and latest GitHub release remain 1.4.0. Use the itch.io package for the updated tutorial. Verified tutorial target: Godot 4.7.2 Windows x64. The sample shop and display are separate example code, not built-in Lite features.

## Update policy
Stable add-on folder, script class names, UIDs and profile schema keep customer resources working between compatible updates. User files stay outside addons. Version details live in plugin.cfg and CHANGELOG.md, not product titles or thumbnails. Lite can be used on its own under MIT. Optional paid editions are available from the creator storefront; no purchase is required for Lite.

## Lumen Vale
Download the optional Editable Example Project, extract it separately and open its project.godot. Run addons/rpg_time/examples/courtyard/main.tscn to explore the original 3D showcase. WASD/arrows move; Shift jogs; E interacts; scroll zooms; H opens photo view; Escape returns or opens help. Visit Mira's market, greet Moss the cat, ring the bell, watch the koi and rest until morning. Original synthesized sounds can be muted. The demo scenery, characters, audio, lighting and shop are optional example code. The Lite product supplies time, seasons, periods and signals.


**Only the Addon Only download is needed to use Time & Seasons. Both Lumen Vale downloads are optional.**
