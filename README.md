# Time & Seasons Lite
A free, MIT-licensed world clock for Godot by Fableweld Labs.

This repository contains source, documentation and development checks. Install releases contain only addons/rpg_time, including the license, quick start, docs and optional example. See [the installation guide](addons/rpg_time/README.md).

[Website and download](https://fableweld-labs.itch.io/time-seasons-free-lite) · [Bug reports](https://github.com/fableweldlabs/time-seasons-lite/issues)

## Update policy
Stable add-on folder, script class names, UIDs and profile schema keep customer resources working between compatible updates. User files stay outside addons. Version details live in plugin.cfg and CHANGELOG.md, not product titles or thumbnails. The companion [Time & Seasons Starter](https://fableweld-labs.itch.io/time-seasons-starter) adds reusable lighting, HUD and game-scene workflows.

## Lumen Vale
Run addons/rpg_time/examples/courtyard/main.tscn to explore the original 3D showcase. WASD/arrows move; E interacts; Escape opens help. The demo scenery, lighting and shop are optional example code. The Lite product supplies time, seasons, periods and signals.
